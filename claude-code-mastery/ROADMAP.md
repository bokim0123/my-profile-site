# 개발자 웹 이력서 프로젝트 로드맵

## 프로젝트 개요
개인 포트폴리오 및 이력서를 소개하는 현대적이고 반응형 웹 페이지를 개발합니다. 
깔끔한 UI/UX와 함께 개발자의 역량을 효과적으로 표현할 수 있는 웹 이력서입니다.

## 기술 스택
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling Framework**: Tailwind CSS
- **Design**: 반응형 디자인 (Mobile-first)
- **Version Control**: Git

## 주요 기능

### 핵심 기능
- [x] 반응형 레이아웃 (모바일, 태블릿, 데스크톱)
- [ ] 개인 정보 섹션 (이름, 직급, 소개)
- [ ] 경력/경험 섹션 (회사, 기간, 담당 업무)
- [ ] 기술 스택 섹션 (언어, 프레임워크, 도구)
- [ ] 프로젝트/포트폴리오 섹션
- [ ] 교육 및 자격증 섹션
- [ ] 연락처 정보 및 소셜 링크
- [ ] 다크모드 / 라이트모드 전환 기능
- [ ] 부드러운 스크롤 네비게이션
- [ ] PDF 다운로드 기능
