# 개발자 웹 이력서 - 개발 로드맵

## 📋 프로젝트 개요

HTML, CSS, JavaScript, Tailwind CSS를 활용하여 **반응형 1페이지 개발자 이력서(웹 포트폴리오)** 를 제작합니다.

**목표:**
- 간단하고 세련된 디자인의 개인 개발자 이력서 사이트 구축
- 모바일부터 데스크톱까지 모든 기기에 최적화된 반응형 디자인
- 기본적인 인터랙션(다크모드, 스크롤 애니메이션 등)을 포함한 동적 웹사이트
- (선택) 정적 호스팅 플랫폼(GitHub Pages, Vercel, Netlify 등)에 배포 가능한 구조

---

## 🛠️ 기술 스택

- **HTML5** — 시맨틱 마크업
- **CSS3 & Tailwind CSS** — 유틸리티 기반 스타일링, 반응형 디자인
- **Vanilla JavaScript** — 다크모드, 스무스 스크롤, 모바일 메뉴 등 경량 인터랙션
- (선택) **Node.js & npm** — Tailwind CLI 빌드 (CDN 방식도 지원)

---

## 🚀 단계별 개발 로드맵

프로젝트 초기화 및 개발 환경 준비

- [ ] 프로젝트 폴더 생성 및 Git 저장소 초기화

### **Phase 1: 기본 레이아웃 & 헤더**

전체 페이지의 뼈대 구조 및 상단 네비게이션 구성

- [ ] HTML 구조 작성
  - [ ] `<header>` — 네비게이션 바 (로고, 메뉴 링크)
  - [ ] `<nav>` — 섹션별 이동 링크 (About, Skills, Experience, Projects, Contact)
  - [ ] 메인 컨테이너 및 기본 섹션 래퍼 추가
- [ ] Tailwind CSS로 기본 레이아웃 스타일링
  - [ ] 네비게이션 바 스타일 (배경색, 글씨 크기, 패딩)
  - [ ] 로고 또는 이름 표시 영역
  - [ ] 모바일 메뉴 토글 버튼 구조 (토글용 체크박스/버튼)
- [ ] 페이지 기본 색상 스킴 정의 (라이트/다크 테마)

---

### **Phase 2: 이력서 핵심 섹션 구성**

각 섹션별 HTML 마크업 및 기본 구조 작성

#### **2-1. 히어로(Hero) 섹션**
- [ ] 프로필 사진 영역 (placeholder 이미지)
- [ ] 이름, 직급/직함 표시
- [ ] 한줄 소개/태그라인
- [ ] CTA 버튼 (이력서 다운로드, 연락처 등)

#### **2-2. About 섹션 (소개)**
- [ ] 짧은 자기소개 텍스트 (100-200자)
- [ ] 개발자로서의 목표/관심사 기술

#### **2-3. Skills 섹션 (기술 스택)**
- [ ] 프로그래밍 언어 (JavaScript, Python, etc.)
- [ ] 프론트엔드 기술 (HTML, CSS, React, Vue, etc.)
- [ ] 백엔드 기술 (Node.js, Django, etc.)
- [ ] 도구 & 협업 (Git, Docker, AWS, etc.)
- [ ] 각 기술별 숙련도 표시 (태그 또는 진행률 바)

#### **2-4. Experience 섹션 (경력)**
- [ ] 경력 항목 구조 (직사, 기간, 직급, 주요 업무)
- [ ] 샘플 경력 2-3개 추가
- [ ] 업무 성과/기여도 시별 표시

#### **2-5. Projects 섹션 (프로젝트)**
- [ ] 프로젝트 카드 레이아웃 (제목, 설명, 기술 스택, 링크)
- [ ] 샘플 프로젝트 2-3개 추가
- [ ] 각 프로젝트별 GitHub 링크, 라이브 데모 링크

#### **2-6. Education 섹션 (학력)**
- [ ] 학력 정보 (학교명, 전공, 졸업년도)
- [ ] 자격증/수료증 (선택사항)

#### **2-7. Contact 섹션 (연락처)**
- [ ] 이메일, 전화번호, 주소 (필요시)
- [ ] SNS 링크 (GitHub, LinkedIn, 블로그 등)
- [ ] 간단한 연락처 폼 (선택사항)

---

### **Phase 3: 스타일링 & 반응형 디자인**

Tailwind CSS를 활용한 전체 시각화 및 반응형 최적화

- [ ] 색상 팔레트 정의 (primary, secondary, accent, text, background)
- [ ] 타이포그래피 설정 (폰트 패밀리, 크기, 라인높이)
- [ ] 각 섹션별 스타일링
  - [ ] 배경색, 패딩, 마진, 테두리 등
  - [ ] 카드, 버튼, 배지 등 재사용 컴포넌트 스타일
- [ ] 반응형 디자인 (모바일 우선)
  - [ ] 모바일 뷰포트 (`sm`, `md`, `lg` 브레이크포인트)
  - [ ] 태블릿 & 데스크톱 최적화
  - [ ] 텍스트 크기, 레이아웃 조정
- [ ] 호버 효과 & 전환 애니메이션 (Tailwind 유틸리티)

---

### **Phase 4: 인터랙션 & 다이나믹 기능 (JavaScript)**

사용자 경험 향상을 위한 간단한 JavaScript 기능 구현

#### **4-1. 다크모드 토글**
- [ ] 헤더에 다크모드 버튼 추가
- [ ] 클릭 이벤트 리스너 구현
- [ ] `dark` 클래스 토글로 전체 페이지 테마 전환
- [ ] 사용자 선택 브라우저 로컬스토리지에 저장

#### **4-2. 모바일 네비게이션 메뉴**
- [ ] 햄버거 아이콘 클릭 → 모바일 메뉴 열기/닫기
- [ ] 메뉴 애니메이션 (슬라이드인/아웃)
- [ ] 링크 클릭 시 메뉴 자동 닫기

#### **4-3. 스무스 스크롤**
- [ ] 내비게이션 링크 클릭 시 부드러운 스크롤
- [ ] 활성 섹션 하이라이트 (스크롤 위치 감지)

#### **4-4. (선택) 추가 기능**
- [ ] 스크롤 시 아이콘/텍스트 페이드인 애니메이션
- [ ] 이메일 클릭 시 복사 기능
- [ ] 연락처 폼 기본 유효성 검사

모든 섹션에 일반적/샘플 이력서 콘텐츠 작성

- [ ] 기술 스택 목록 완성
- [ ] 경력 정보 입력 (직사명, 기간, 직급, 업무 설명)

- [ ] 학력 정보 입력
- [ ] 연락처 정보 입력 (이메일, GitHub, LinkedIn 등)
- [ ] 전체 텍스트 검토 & 오타 수정
